# 🎮 C# Console Games

A collection of classic arcade games written in **C#** as console applications:

| Game | Description |
|---|---|
| 🐍 Snake | The classic snake game |
| 🧱 Tetris | Block-stacking puzzle game |
| 🏓 Ping Pong | Two-player pong |
| 🟦 Tron | Light-cycle duel |

## 🛠️ Getting Started
Open `CSharpConsoleGames.sln` in Visual Studio and press **F5** (any .NET
Framework SDK will do).

Each game is a standalone console project inside the solution:
- `Snake/` · `Tetris/` · `PingPong/` · `Tron/`
